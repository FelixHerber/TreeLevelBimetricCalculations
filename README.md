# TreeLevelBimetricCalculations
The tree-level scattering amplitudes of bimetric theory. 
Also contains an expansion of bimetric theory to quartic order in the mass eigenstates. 
Uses Mathematica together with the packages xAct, FeynRules, FeynArts and FeynCalc.
